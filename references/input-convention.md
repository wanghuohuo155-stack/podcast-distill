# 输入约定（阶段 1 第 1 步：先定义输入长什么样）

## 输入形态

播客/长音频的**转写纯文本**（TXT），允许混用两种内容：

1. **自由对话行**：`[00:01:20] 嘉宾：……`——作为上下文保留，不参与规则提取（M2 LLM provider 再覆盖）。
2. **结构化标记行**（规则提取的主要来源）：

| 标记 | 含义 | 示例 |
|---|---|---|
| `[要点]` | 洞见 | `[要点] 决定前先写失败清单` |
| `[行动]` | 行动建议 | `[行动] [00:28:00] 下期节目发布前用失败清单过选题` |
| `[金句]` | 值得原样引用的句子 | `[金句] "园丁种下种子之前不会问它什么时候开花"` |
| `[案例]` | 真实案例 | `[案例] 上次产品改版：先列 12 种失败方式` |
| `[原则]` | 可复用原则 | `[原则] 预算不足时优先砍非核心功能` |

## 降级路径

无标记的纯自由对话转写：mock 提取器返回 0 条候选并明确提示"提取率取决于文本可解析度"；
LLM provider（M2）落地前不宣称支持自由文本高价值提取。

## 金句与行动的领域规则

- 金句必须被引号包围（`""` 或 `「」`），否则 unverified
- 行动必须含时间点（`[hh:mm:ss]` 时间戳或"下期前/本周/月底"相对词），否则 unverified
